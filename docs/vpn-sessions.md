# L2TP accounting
Migration 0017 adds nullable classification and partial indexes to radacct. After normal SQL accounting, validated l2tp realm packets tag rows by acct_unique hexadecimal key and actual source NAS IP. Historical rows remain unknown. Tagging is a separate SQL operation and can fail independently; monitor SQL errors. Realm is a configured service policy, not independent proof of physical tunnel protocol. Open means no Stop, not verified tunnel availability. Stale uses three current interim intervals, minimum 15m; summary uses fixed 15m. Counters are cumulative octets, not bandwidth. Exact filters, cursor pagination and optional 30s polling. No automatic closure or disconnect. Build, configuration and accounting tests pending.
