# VPN pool inventory
Migration 0016 registers one contiguous IPv4 range per named RouterOS pool on each NAS. API serializes pool creation, deletion, user assignments and profile/group edits with the existing PPP advisory lock. It rejects overlaps within a NAS or shared address space and static assignments inside registered ranges, including disabled users. Dynamic users referencing a registered pool must match its address space. Unregistered pool names remain permitted for backward compatibility. Capacity is configured range size, not live availability. No NAS synchronization, multi-range pools, exclusions, reservations or common IPAM integration yet. No runtime changes. Also fixes missing address_space_id SQL argument in assignment update. Build and integration tests pending.
