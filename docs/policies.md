# Policy engine — first slice
Group network policy writes allowlisted SQL attributes only. VLAN uses Tunnel-Type=VLAN, Tunnel-Medium-Type=IEEE-802 and Tunnel-Private-Group-Id. Null removes the corresponding managed attribute. Changes affect all group members, not only a specific service; use dedicated groups. Simultaneous-Use is configured but enforcement and concurrent login behavior require lab testing. Device role mappings are stored separately and never emitted as RADIUS reply attributes yet. The PPP virtual server rejects explicit administrative/login/authenticate-only Service-Type requests. This is not a comprehensive service classifier: do not enable administrative RADIUS on NAS until dedicated isolation and negative tests exist. MAC authentication, EAP and proxy remain unimplemented.
