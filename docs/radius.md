# RADIUS integration (development)
Debian Bookworm packaged FreeRADIUS 3.x is used rather than pinning an unverified 3.2 image. PostgreSQL uses an additive compatibility schema, not the complete upstream schema. The local virtual server enables PAP, CHAP, MS-CHAP and SQL accounting. EAP, post-auth logging, external NAS, database role separation and production hardening are not yet enabled. The RADIUS client is restricted to container loopback. Run docker compose exec radius freeradius -v to inspect the actual version. Run sh scripts/smoke-radius.sh to check rejection after startup. An end-to-end accept and accounting test remains required.
