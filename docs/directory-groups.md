# AD security group inventory (66.0.4)

Migration 0030 creates directory group and direct membership observation tables. Groups are identified by profile/objectGUID. Discovery uses AD security-enabled groupType bit. Sync reads the selected group by GUID and direct memberOf matches within configured Base DN, then replaces only the inventory snapshot for already imported users. Rejects incomplete results above 200, LDAP errors or missing GUIDs. Nested, primary, cross-base and foreign-domain membership are not expanded. AD reads are not a transactional directory snapshot. No local authorization memberships or grants are modified. Personal-admin API only, no runtime grants. UI discovers groups after selecting a directory profile via Catalog. Build, migration and live AD verification pending.
