# FreeRADIUS 3.2 PAP compatibility
The internal dictionary in release_3_2_1 defines SSHA2-512-Password (octets), not SSHA512-Password. Device AAA and Hotspot fetch existing base64 SHA512(password + 16-byte salt) + salt into Tmp-String-0, validate its 108-character format (107 base64 characters and one padding character), and pass Password-With-Header with {ssha512} to rlm_pap for decoding. No credential migration is required. Runtime authentication tests remain necessary. Upstream: https://github.com/FreeRADIUS/freeradius-server/blob/release_3_2_1/share/dictionary.freeradius.internal
