# Service accounts
Personal administrators issue independent zrs_ bearer credentials for machine integration. 256 bits random; SHA-256 digest only in DB; token returned once with Cache-Control no-store. Scope checks use explicit FastAPI route templates, deny all other endpoints including IAM. Account disable revokes all tokens irreversibly. Tokens expire after 1–365 days. Rotate by issuing a replacement and revoking the old token. No delete-user scope, no NAS/PKI writes. Scopes are global across ZRADIUS subscribers, not tenant-specific. Use TLS or trusted VPN, never log Authorization. For ZBSS choose only users:read, users:create, users:state, users:groups, accounting:read and optionally sessions:disconnect; password changes need explicit users:password. Audited actor is service:<token UUID>. In-flight requests may finish after revocation. No automatic rotation or service-token rate limiter yet. Apply migration 0008 with migrate service. FreeRADIUS unchanged. Tests added but not executed in this environment.
