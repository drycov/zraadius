# Group accordion UI
Subscriber groups, device user groups and NAS groups now use one shared disclosure component with inline expansion, search, one expanded group per list, keyboard-accessible native buttons and design-kit theme tokens. Device group details split into members, per-NAS grants and NAS-group grants. NAS group details split into membership, CIDR and adding devices. Closed panels unmount their content: requests are deferred until expansion and unsaved form entries are discarded on collapse. No API or database changes. Playwright coverage added for subscriber group navigation; runtime tests pending.
