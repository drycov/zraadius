# Group VPN templates
0021 adds group templates referencing registered NAS, PPP profile and optional address space. Only dynamic pool assignments; no shared static IP. Preview resolves distinct tuples across current memberships, denies missing/conflicting templates, and validates existing pool policy. Apply rechecks under PPP lock, requires central NT credential, refuses to replace existing individual assignment and creates disabled VPN row. Explicit enable required. This is a provisioning template, not live inheritance; changing/removing group membership does not revoke existing copied assignments. Live inheritance requires a separate allocation and runtime policy redesign. API role only, no RADIUS changes. Tests/build pending.
