# Unified identity (phase 1)
0018 adds central identities and optional composite foreign keys to existing Device AAA and L2TP rows. Existing users remain independent; no automatic matching. New identities can create both service records atomically with a single password; hash material remains in service tables for compatibility. FreeRADIUS checks global enabled on authorization and post-auth queries for linked records. Per-service state retains grants. Independent password rotation is rejected for linked rows. Existing service APIs remain available for legacy records. Unified UI currently creates assignments only at initial creation, toggles existing service grants and resets linked passwords. No additional service assignment after creation yet, no PPPoE/EAP/console integration, no historical linking, no session termination. Login collision checks are advisory against legacy APIs, not a cross-catalog DB constraint. Build and integration tests pending. Deploy migrate/API/web/radius together.
