# RADIUS pool staging
This is a staging layer, not a live radippool schema. Export an IPv4 IPAM pool (maximum 65536 addresses); reserved/allocated IPAM addresses and existing IPoE static addresses are excluded. While staged, IPAM allocation/release is blocked. Group bindings are metadata only and do not emit Pool-Name or Framed-Pool. Withdrawal requires removing group bindings. No changes to FreeRADIUS runtime or accounting. Future adapter must verify the packaged FreeRADIUS PostgreSQL sqlippool schema and queries, enforce cross-system exclusion, and test lease allocation, renewal and release. Do not use staging data as DHCP leases.
