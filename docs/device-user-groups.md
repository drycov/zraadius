# Device AAA user groups
Groups are separate from IAM and subscriber profiles. Explicit membership and per-NAS group grants are optional; no default groups or automatic enrollment. Effective resolution: enabled user, registered MikroTik NAS with device-aaa service; direct grant overrides inherited grants; identical inherited role/filter pairs coalesce; conflicting pairs produce no grant and reject. Removing direct access can reveal inherited access, so remove group membership/grants or disable user for full revocation. Existing sessions are not disconnected. Effective view uses PostgreSQL 15+ security_invoker and is SELECT-only for runtime. API and FreeRADIUS query the same view. Refresh effective permissions in UI after edits. No CIDR, NAS groups, legacy import or automatic provisioning yet. Migration 0010 requires coordinated API and radius update. Runtime and builds must be tested locally.
