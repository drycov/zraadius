# Device AAA reply profiles
Migration 0012 introduces named immutable templates for Mikrotik-Group and optional Filter-Id. Seeded templates confer no permissions by themselves. Assign by sending {"profile_id":1} instead of manual {"role":"read","filter_id":"global-read"}. Mixed inputs reject. The resolved attributes are copied into the existing grant and profile_id retained for provenance. All three grant types support profiles. A profile is not a live policy link: create a new profile and explicitly reassign to change access. Conflict resolution compares actual role/filter values, not profile IDs. Runtime remains unchanged and does not need profile table privileges. Arbitrary attributes and authentication control attributes are not supported.
