# IPoE / MAC inventory
Assign the ipoe service to a registered NAS first. Bindings are unique per NAS/MAC and per NAS/static IPv4; overlapping IP space between NAS is allowed intentionally. Optional Circuit-ID and Remote-ID are exact strings (not decoded vendor binary TLVs). Preview checks the registered NAS/service and enabled binding, and denies unknown or mismatched identities. This is an authenticated management preview, not a live RADIUS authorization endpoint. MAC addresses are spoofable: require trusted access ports and DHCP snooping/Option 82 at the edge. No Auth-Type Accept or automatic MAC-as-password credentials are inserted into radcheck. NAS deletion with bindings is restricted. Next: dedicated IPoE virtual server, vendor-specific packet mapping, negative AAA integration tests and IP pool allocation.
