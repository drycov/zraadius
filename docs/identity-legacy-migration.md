# Legacy identity migration

Personal administrator only. GET /identities/legacy-candidates lists independent Device AAA or L2TP users without hashes. POST /identities/legacy-migrate accepts service, user_id, preview (default true), and a new password on apply. Preview checks exact-name conflicts; apply rechecks under locks. No automatic merging. Existing service row ID, grants, group membership, profile, static address and local enabled state are retained. The transaction temporarily renames the legacy row to satisfy the immediate namespace trigger, then restores the original login with the new identity link and clears local hashes. Other transactions do not see the intermediate rename. Global identity starts disabled; explicitly enable after verification. Existing network sessions are not terminated. Generic radcheck, EAP, IAM and vouchers are not migrated. No migration file needed; runtime and build verification pending.
