# VPN Disconnect
Dedicated POST /api/v1/ppp/sessions/{id}/disconnect reuses the existing RFC 5176 transport and shared request journal. Requires an open explicitly classified L2TP record, registered MikroTik NAS and current l2tp service binding; global COA_ENABLED and COA_ALLOWED_NETWORKS still apply. Admin/operator may invoke; auditor and service tokens cannot use this new endpoint. UI shows capability and command history. ACK does not close accounting; only actual Stop does. Existing generic session endpoint remains unchanged. No automatic disconnect on blocking, no bulk operations, no change-rate support, no retry of stuck pending requests in this stage.
