# Unified service policies
Identity detail reads direct Device AAA grants, Device group membership and current L2TP assignment. Device policy replaces direct grants and membership atomically after validation; inherited NAS group grants themselves are unchanged. Reply profiles or manual roles supported. VPN policy edits existing NAS/profile/group/address space/static IP without changing credentials or enable flags. Existing services must be provisioned first. Changes do not terminate sessions. No schema migration. UI exposes policies inside user editor. Build and integration verification pending.
