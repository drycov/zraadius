# ZRADIUS UI
Full migration from Ant Design to vendored drycov/design-kit v0.3.0 (cd8b60c5d93ded440bfe20c69d29042330da202f). All existing page components and API calls preserved. Local UI extensions provide form state/validation, selects, numeric inputs, tables with pagination, native accessible dialogs, confirmations, navigation, toast feedback, icons, and browser-local QR rendering via qrcode. No antd or @ant-design/icons dependencies. Theme uses kit CSS tokens. The local API adapters are intentionally limited to features used by ZRADIUS; they are not a general Ant Design replacement. Build and browser integration tests must pass before release.

Frontend pages now load on demand through React.lazy; hash routing works with static nginx and browser history. Shared hooks and UI forms/table/dialog/primitives are separate modules. Playwright smoke test mocks API to validate login, navigation and NAS form payload; it does not validate backend. Large table virtualization and upstream design-kit extensions remain outstanding.
