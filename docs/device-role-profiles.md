# Custom Device AAA roles
Migration 0009 adds a separate RouterOS role catalog (read, write, full, forbackup) and nullable per-NAS grant Filter-Id. Register any safe ASCII group name and assign it explicitly to an existing user and Device AAA-enabled NAS. Actual RouterOS group must already exist locally. The server checks PAP credentials and rechecks grant after authentication; it returns Mikrotik-Group and optional Filter-Id from a single SQL result. No unknown-user fallback, no broad network client registration. Existing grants preserved. Do not import exposed credentials; rotate them. Update migrate, api, web and radius together, retaining pgdata and encryption key. Custom group and Filter-Id behavior must be tested on actual RouterOS. Group membership, CIDR and legacy importer are later phases.
