# Management API
User details, password reset, enable/disable, deletion, group removal and MikroTik group profiles are available in Swagger. Blocking sets Auth-Type := Reject and does not disconnect existing sessions. This prototype owns the Auth-Type attribute; importing custom Auth-Type policies is not supported. NAS registration is inventory only, not runtime deployment. The SQL module still has read_clients = no; external NAS remains disabled. Secrets are never returned by the API, but are stored in plaintext in the development DB. Do not expose this stack to untrusted networks. The dictionary endpoint is a curated starter catalog, not a dictionary parser. Runtime integration tests and production RBAC remain outstanding.
