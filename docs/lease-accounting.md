# Experimental lease correlation
A generation UUID is reset on each SQL allocation and returned in Class. An Accounting row can attach to the current generation only if Class, address, username, NAS and start time match. Stop releases only the attached Acct-Unique-Session-Id; old generation tokens cannot release newly assigned addresses. This relies on NAS echoing Class and the packaged SQL accounting queries persisting it; validate actual encoding and NAS clock behavior. No renewal yet: Session-Timeout remains bounded to 3600 seconds and the lease is not extended, avoiding reuse while a compliant NAS is online. Missing Class, missing Start or mismatches fall back to expiry. No bulk release on NAS reboot. Experimental, not production-ready.
