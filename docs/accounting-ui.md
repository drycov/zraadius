# Accounting console
Existing GET accounting retains limit/offset/active compatibility. Optional username exact match, NAS IP filter, before ID cursor and ASC/DESC allowlisted order. Cursor mode requires descending order and offset zero. UI fetches 101 records to display 100 and determine next-page availability, keeps a cursor history, resets on filter change, does not load all sessions. Three indexes in revision 0007 support common queries; index creation is transactional and may block writes on large existing tables, schedule maintenance. No row virtualization yet: capped pages avoid unnecessary DOM volume and preserve variable-height action rows. API and browser smoke tests are not verified.
