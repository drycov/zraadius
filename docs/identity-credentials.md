# Central credentials
0019 moves linked SSHA512 and NT hash into zradius_identity_credentials. Independent legacy rows keep their hashes; linked rows must have NULL local credentials. Existing linked accounts with inconsistent hashes or no service require password reset; Device-only migrated accounts lack NT hash and require password reset to add L2TP. No plaintext recovery. New identities store both representations even without services. FreeRADIUS uses central hashes for linked accounts and never falls back to local hashes. Global enabled remains enforced. PUT identities/{id}/services supports optional assignments and atomic service changes; existing grants retained on disable. UI adds missing services via checkbox and fields; editing existing service-specific assignments remains available in existing service screens. Password reset and service change in UI are two separate transactions. Legacy login collision constraints and remaining services pending.
