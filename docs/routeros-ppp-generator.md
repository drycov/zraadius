# RouterOS PPP configuration generator
Admin-only POST /api/v1/ppp/routeros-config generates review-only sections for registered MikroTik NAS with l2tp binding. IPv4 only. NAS registry address supplies src-address; operator must verify it is actually local to the router and routed toward RADIUS. API egress is separately supplied for optional Disconnect. No secrets retrieved or returned. All mutating commands are commented; download is a review file, not an executable migration. No automatic application. Existing RADIUS entry order and PPP AAA settings must be reviewed; service=ppp is not protocol-specific. Optional enabled user bound to NAS gets exact-name, service=l2tp cutover and rollback commands; enabled does not prove tested authentication. Local users and profiles are not removed. No DB migration. Unit tests added to CI, build/live checks pending.
