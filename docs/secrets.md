# Shared secret encryption
AES-256-GCM v1 envelope with random 96-bit nonce and associated data table:identity. Migration 0003 encrypts existing valid alphanumeric NAS/proxy secrets transactionally and refuses unsupported values. Back up database and existing keys before upgrade. Stop API/radius, add ZRADIUS_SECRET_KEY (openssl rand -hex 32) to .env once, rebuild and migrate. Preserve the key separately from database backups. Never regenerate it on restart. API decrypts only for CoA; runtime startup renders validated clients/proxy config, then removes key from daemon environment. Docker environment remains accessible to privileged operators. Generated files contain plaintext; permissions restrict access but container filesystem and backups may retain it. Old database backups/WAL may contain plaintext; rotate actual NAS secrets as operationally appropriate. No key rotation workflow yet; v1 is envelope format version, not a key identifier. PPP Cleartext-Password, NT hashes and other credentials are not covered. CI tests added, actual migration and optional runtime validation pending.
