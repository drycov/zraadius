# VPN address spaces
0015 adds optional logical address spaces and a partial unique index across NAS for static IPv4 assignments in the same space, including disabled users. Existing rows remain unassigned and retain the original NAS-scoped uniqueness constraint. Different spaces can reuse addresses across NAS; same-NAS duplicates remain prohibited. The conflict report lists repeated addresses involving unassigned users (up to 500). Assign every user in a shared routing domain to the same space for enforcement. This is inventory only, not VRF provisioning, live IPAM allocation or pool overlap detection. Named RouterOS pools remain external and must be audited separately. No FreeRADIUS policy changes.
