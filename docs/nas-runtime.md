# NAS runtime and RFC 5176 (development)
Default remains loopback-only and CoA disabled. Set RADIUS_ENABLE_NAS=true and RADIUS_BIND_IP to a trusted host interface address; restrict UDP 1812/1813 with firewall. Recreate radius after NAS changes; it reads an explicit snapshot at startup and validates configuration. No automatic reload, rollback or runtime status yet. All registered valid NAS are included when enabled; deletion/secret changes require restart. Do not expose to the Internet. Message-Authenticator is required on Access-Request, so verify NAS firmware compatibility.
For CoA, set COA_ENABLED=true and COA_ALLOWED_NETWORKS to explicit comma-separated CIDRs (no broad networks). Ensure container routing and NAS firewall permit UDP 3799 from the actual Docker egress source. MikroTik /radius incoming set accept=yes port=3799. Verify support for CoA rate changes on the specific service. The API only sends to registered NAS with open accounting records; ACK does not close accounting. Unknown means delivery uncertain; inspect NAS before retrying. Pending rows after a crash require manual reconciliation. Secrets remain plaintext in DB; no production usage yet.
