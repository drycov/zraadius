# Grouped sidebar navigation
All 17 existing routes are preserved. Dashboard is standalone; other routes are grouped into subscriber access, network infrastructure, RADIUS/AAA, monitoring/audit and administration. Groups expand independently; route changes open the active group automatically, including hash links and browser history. Expanded group IDs persist in localStorage (no credentials or identity). Existing role filtering is applied before rendering groups; backend RBAC is unchanged. At widths <=900px a navigation toggle displays the vertical menu; selecting a route closes it. Native buttons, aria-expanded/controls/current, focus styles and reduced motion are supported. Playwright scenarios updated; build and runtime verification pending. No API, database or RADIUS changes.
