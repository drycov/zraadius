# Experimental SQL IP Pool runtime
Schema follows FreeRADIUS release_3_2_1 PostgreSQL sqlippool. Stage an IPv4 pool, activate via POST /api/v1/ipam/pools/{id}/radius-activate, bind to a group via PUT /api/v1/groups/{group}/radius-pool. Enable RADIUS_ENABLE_SQLIPPOOL=true and recreate radius and api. Use isolated lab ranges only. NAS must enforce Session-Timeout (max 3600 seconds); this initial implementation relies on lease expiry and deliberately does NOT process Accounting renew/release yet, avoiding premature reuse due to delayed Stop packets. No automatic deactivation or deletion of live pools. Existing local Framed-Pool and Framed-IP-Address are incompatible with selected SQL pool. No production deployment until configuration and concurrent allocation tests pass. The env flag indicates intended configuration only, not proof of running state.
Upstream: https://github.com/FreeRADIUS/freeradius-server/tree/release_3_2_1/raddb/mods-config/sql/ippool/postgresql
