# Experimental IPoE runtime

Use the compose.ipoe.yaml overlay to enable a separate UDP 18120 listener. Register NAS by its actual source IPv4 and assign ipoe service, enable RADIUS_ENABLE_NAS=true, restart radius, create an enabled static IPoE binding. On a compatible MikroTik DHCP RADIUS client configure authentication port 18120. Restrict access to trusted NAS IPs and verify Message-Authenticator support; never expose this service publicly. A MAC is an identifier, not proof of device identity; DHCP snooping and access-port protections are required.

The virtual server accepts only strict MAC User-Name formats, queries bindings scoped to packet source and IPoE service, and returns Framed-IP-Address only for enabled static bindings. No PPP credential lookup. Option 82 constrained bindings and dynamic-only bindings are rejected deliberately until vendor-specific decoding and lease allocation exist. The global client registry still applies to both listeners; enabling IPoE does not isolate PPP access for existing multi-service NAS. Docker NAT must preserve NAS source address. Loopback has no registered binding and is rejected. No DHCP accounting or lease revocation is implemented. Validate on isolated lab before deployment.
