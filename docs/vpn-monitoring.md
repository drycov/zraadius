# VPN monitoring
GET /api/v1/ppp/monitoring provides a repeatable-read read-only snapshot of inventory and explicitly classified L2TP accounting. No historical backfill or simulated data. State threshold uses three current profile interim intervals with 900s minimum; missing update is unknown. NAS table includes up to 500 NAS with open records, not a reachability probe. RX/TX are cumulative counters for open records (decimal strings to preserve integer precision), not daily volume or bandwidth. Starts/stops and Disconnect outcomes use rolling 24h windows. UI refresh is manual or optional every 60s while visible. Existing GET RBAC applies. No migrations or FreeRADIUS changes. Build and runtime tests pending.
