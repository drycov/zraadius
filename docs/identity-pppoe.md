# Unified PPPoE phase 1
0022 introduces one NAS-scoped PPPoE assignment per identity, configured NAS-local named pool, rate and interim interval. Unified PAP/MS-CHAPv2 credentials; CHAP unsupported because no cleartext password. Explicit PPPoE realm, NAS source registration and global/service state required. Existing legacy PPPoE SQL remains separate; exact unified usernames never fall through on missing/disabled assignment. Local smoke-test path rejects unified usernames. No SQL IP pool allocation, static address, group/tariff mapping, simultaneous-use enforcement or ZBSS integration in this phase. NAS pool existence requires operator validation. No session termination. Build and actual RADIUS tests pending.
