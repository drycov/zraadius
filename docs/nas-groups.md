# NAS groups and CIDR selectors
Migration 0011 adds explicit NAS membership and canonical IPv4/IPv6 CIDR selectors, with nonzero prefix. PostgreSQL 16 required for pg_input_is_valid. Selectors match registered NAS only; they do not create RADIUS clients, share secrets or enable services. Device user group to NAS group grants are inherited alongside existing per-NAS group grants, conflicts reject unless a direct user grant exists. Future registered matching NAS inherit access automatically; review CIDR breadth carefully. Removing explicit membership does not override CIDR membership. Actual IPv6 RADIUS transport is not enabled by this change. Existing runtime uses the same effective grants view. No wildcard network clients or Auth-Type Accept fallback.
