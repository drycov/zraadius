# RouterOS PPP import
Paste a redacted /ppp export (no passwords) into PPP/VPN Import. Restricted parser supports add records, quoted values and ordinary line continuation; rejects expressions, escapes, unsupported secret properties and ambiguous service=any. Non-PPP sections ignored. Only explicit service=l2tp is imported. Profiles reference existing RouterOS names/pools; other profile settings remain on the router. Existing profiles reused only if pool matches; existing usernames and duplicate static IPs block apply. Preview has no writes. Apply repeats checks under PPP advisory lock, commits atomically, and creates disabled users with random unknown credentials, regardless of original disabled flag. Set new password before enabling. No automatic router changes, no overwrite or password import, no pool-range import. Max 256 KiB and 500 records. No schema changes. Unit tests added to CI; live integration pending.
