# Unified EAP phase 1
0024 introduces separate per-identity dot1x and wpa-enterprise assignments, each one registered NAS and optional VLAN. NAS must advertise exactly one EAP service; mixed-service NAS are denied for unified identities because the existing outer protocol does not reliably distinguish wired and wireless. Inner PEAP tunnel queries central NT hash, global/service state and actual outer packet source; legacy EAP remains available only when username is not in unified identities. EAP-TLS certificate authentication is independent and not changed. EAP remains opt-in via existing compose overlay; client must validate server CA/name. Disable denies new authentication, no active-session disconnect. Deployment and positive/negative integration tests pending.
