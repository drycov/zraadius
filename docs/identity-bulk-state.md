# Bulk identity state

POST /api/v1/identities/bulk-state requires a personal administrator. Accepts 1–100 distinct IDs, enabled boolean and preview (default true). Locks IAM policy and selected rows. Rejects blocking the caller or all remaining effective administrators. Preview rolls back state and web-session deletes. Apply revalidates and commits atomically. Blocking revokes existing web sessions, preserves service assignments and credentials; enabling does not restore revoked sessions. The UI links to existing per-user session controls after blocking. Disconnect is explicitly separate; ACK is not Accounting-Stop, CoA may be disabled or fail. No bulk network sends. Audit records changed identities and web revocation targets. No migration.
