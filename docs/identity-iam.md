# Unified IAM
0025 links management accounts explicitly; legacy administrators remain independent. Central credential row stores Argon2id alongside network hashes; linked IAM password_hash is an unrelated random verifier, never used for linked login. Session lookup and login check global identity state. Role/state changes revoke sessions and protect last effective administrator. Existing MFA enrollment/recovery preserved. Unified password reset revokes web sessions; linked self-service password change updates all three representations. New console assignments require a personal admin, existing identities require password reset if Argon2id missing. No plaintext conversion. Machine service accounts independent. Shared network/web password increases blast radius; require strong client certificate validation and enroll MFA. Existing MFA is not mandatory by this migration. Tests/build pending.
