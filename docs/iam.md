# Management IAM
Management identities are independent of subscriber, EAP and device AAA users. Argon2id (64 MiB, 3 iterations, parallelism 2), opaque 256-bit bearer sessions with SHA-256 digests in PostgreSQL and 8h expiration. No JWT/refresh or MFA yet. Use TLS for any remote UI; browser token is memory-only. Bootstrap once with docker compose exec api python bootstrap_admin.py (interactive). ADMIN_TOKEN is disabled by default; enable ZRADIUS_LEGACY_TOKEN_ENABLED=true only for controlled transition/CI. Legacy token grants full admin. Roles: admin all; auditor GET on existing AAA APIs; operator read and session disconnect/rate. This is coarse authorization, not object-scoped RBAC. Login limiter uses global and username buckets (can deny service if abused); reverse proxy limits also required. No password recovery/rotation UI or IAM user management UI yet; management account creation and blocking via API. Existing sessions are revoked on disable/logout; in-flight authorized requests can complete. Audit actor added. Verify migration, auth and frontend builds before production.
